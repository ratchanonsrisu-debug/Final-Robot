## ทำงานยังไง
- `robots.scan_all()` หัน gimbal อ่าน ToF ทีละทิศอยู่แล้ว กล้องอยู่บน gimbal เดียวกัน → หลังอ่านแต่ละทิศเรียก
  `TargetHunter.look(d, tof)` ถ่ายภาพหาป้าย (ไกลได้ ~4 ช่อง) แปลงเป็นพิกัดโลกบันทึกลงแผนที่ = รู้ล่วงหน้าว่าป้ายอยู่ไหน
  โดยไม่ต้องก้ม gimbal เช็คทีละช่อง และไม่เสียเวลาเพิ่ม (สแกนก่อนเดินทุกช่อง = ดูช่องถัดไปก่อนเข้าเสมอ)
- ยิงระหว่างสำรวจ (`after_scan`) เฉพาะเมื่อเข้ากติกาทุกข้อ แล้วสำรวจต่อ (ไม่ขยับหุ่นเพิ่ม):
  ช่องป้ายอยู่ **แนวตรง** กับช่องหุ่น ห่าง 1–2 ช่อง (ห้ามทแยง/ห้ามช่องเดียวกัน) ทางตรงโล่ง, ระยะ **60–80 ซม.**,
  เป็นเป้าที่กำหนด, เห็นจาก ≥2 ช่องตำแหน่งตรงกัน, เห็นนิ่ง ≥2/3 เฟรม → **ล็อคก่อน (ยังไม่ยิง)** → ตรวจป้ายที่ล็อค
  (สี/รูป/ตำแหน่งห่างเป้า ≤12 ซม./ขนาดกว้าง-สูงสอดคล้อง/ยังอยู่แนวตรง) → ยิง
- สำรวจครบแล้วยังมีเป้าค้าง (`sweep`) → วางเส้นทางสั้นสุดไปช่องยิง ยอมระยะ 35–115 ซม. (ไม่เกิน 2 ช่อง) ก่อนกลับบ้าน
- รอบ 2 (`run_round2` → `plan_route`): ลองทุกลำดับเป้า + เลือกช่องยืนยิงของแต่ละเป้า ให้ระยะเดินรวมสั้นสุด
  (หลายเป้ายิงจากช่องเดียวกันได้) ช่องที่ได้ระยะ 60–80 ซม. ได้รับความสำคัญก่อน
- กันของหลอก/กำแพงสี: ตัดป้ายที่อยู่ "หลังกำแพง" (ไกลกว่าที่ ToF วัดได้ หรือเส้นมองผ่านกำแพงในแผนที่),
  ต้องเห็นจากหลายช่องตำแหน่งตรงกัน, ป้ายสีเดียวกันคนละรูปที่อยู่ติดกันไม่ถูกรวม (ป้ายเรียงแถว)
- การเชื่อมต่อหุ่นมีชุดเดียว (`RealRobot`) — `RealShooterIO` ยืม `_ep` มาเปิดกล้อง/ยิง ไม่เปิด connection ซ้ำ
- ค่าทั้งหมดอยู่ใน `config.py` หมวด "ยิงเป้า"
