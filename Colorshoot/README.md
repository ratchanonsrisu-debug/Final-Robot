# RoboMaster EP — Color Sign Shooter

โปรแกรมตรวจจับป้ายสีด้วยกล้องบน gimbal เล็ง และยิง (IR หรือเจล) พร้อม dashboard สำหรับ
calibrate สี ตั้ง ROI ตัดโซนที่ไม่ต้องการ ล็อคมุม gimbal และ calibrate จุดกระทบให้ตรงกับที่ยิงจริง

ป้ายที่รองรับ (นับเฉพาะส่วนที่มีสี): สี่เหลี่ยมตั้ง 6×9 ซม., สี่เหลี่ยมนอน 9×6 ซม., จัตุรัส 7×7 ซม., วงกลม ø7 ซม. (r = 3.5 ซม.)
สีตั้งต้น: RED / YELLOW / GREEN / BLUE (เพิ่มสีได้ใน dashboard)

## Calibrate จากป้ายจริง 4 ใบ (แท็บ "Calib 4 ป้าย") — แนะนำให้ทำก่อนอย่างอื่น
1. วางป้าย 4 ใบเรียงกัน (แดงตั้ง / เหลืองนอน / เขียวจัตุรัส / น้ำเงินวงกลม) ให้เห็นครบในภาพ หุ่น + gimbal นิ่ง
2. ถ้าวัดได้ ใส่ **ระยะจากกล้องถึงแนวป้าย** (ซม.) → โปรแกรมจะหา HFOV และเช็คขนาดป้ายให้ด้วย (0 = ข้าม)
3. **▶ เริ่มเก็บภาพ + calibrate** (ค่าเริ่มต้น 15 วิ, 1 ภาพทุก 0.3 วิ) ระหว่างนั้นห้ามเดินผ่านหน้ากล้อง
4. โปรแกรมทำเอง:
   - หาก้อนสีอิ่มแต่ละสี (ลองหลายเกณฑ์ S แล้วตัดก้อนที่ใหญ่เกิน/แตะขอบภาพ/ไม่ทึบ = กำแพง)
     → รวมพิกเซลเนื้อสีจาก **ทุกภาพ** แล้วเรียนช่วง HSV + histogram
   - ถ้าเจอพื้นที่กว้างสีเดียวกับป้าย (เช่นกำแพงเหลืองของสนาม) จะตั้งขอบล่าง S ให้อยู่ระหว่างกำแพงกับป้ายอัตโนมัติ
   - ตรวจจับทุกภาพด้วยค่าเดิมเทียบค่าใหม่: อัตราเจอ, รูปทรงถูกไหม, ระยะ, การสั่นของตำแหน่ง
   - ลดเกณฑ์รูปทรงให้เฉพาะป้ายที่ยังตรวจไม่เจอเท่านั้น
5. ดูผลในช่อง log แล้วกด **💾 บันทึก** (ไม่พอใจกด **↩ ย้อนค่าก่อน calibrate**)

ผลอยู่ที่ `logs/calib_session_<เวลา>/`
```

annotated/           ภาพที่วาดผลตรวจจับ + ROI ปัจจุบัน (เหลือง) + ROI ที่แนะนำ (เส้นประม่วง) ใช้ดูตอนตั้ง ROI
masks/               mask ของแต่ละสี (ทุก 10 ภาพ) ขาว = ผ่าน
compare_old_new.jpg  ภาพแรก ค่าเดิม (ซ้าย) vs ค่าใหม่ (ขวา)
detections.csv       ทุกป้ายที่ตรวจเจอทุกภาพ (ค่าเดิม/ค่าใหม่): ตำแหน่ง, ขนาด, ระยะ, aspect, rectangularity, ...
summary.txt/.json    สรุปผล (json ใช้ต่อในโปรแกรมอื่น/รายงานได้)

```
ROI ที่แนะนำคิดจากป้ายที่ระยะนี้เท่านั้น (ป้ายที่ใกล้/ไกลกว่าจะอยู่สูง/ต่ำต่างไปในภาพ) กดใช้ได้ด้วยปุ่ม "ใช้ ROI ที่แนะนำ"
แต่ควรดูภาพใน `annotated/` ก่อน

## ลำดับการเตรียมก่อนวันแข่ง (สำคัญ ทำตามลำดับ)
1. **แอป RoboMaster → Settings → System → Calibration → Gimbal** (ถ้า pitch ไม่ขนานพื้น)
2. `python run.py` → เลือก **หุ่นจริง** → **เชื่อมต่อ**
3. แท็บ **Gimbal** → **ตรวจทิศการหมุน gimbal อัตโนมัติ** (หันกล้องไปทางที่มีลวดลาย ไม่ใช่ผนังเรียบ)
4. แท็บ **Calibrate → 1) HFOV**: วางป้าย 1 ใบตรงกลางภาพที่ระยะที่วัดด้วยตลับเมตร (เช่น 100 ซม.)
   → ใส่ระยะ → **คำนวณ HFOV** (ระยะที่โปรแกรมคำนวณจะถูกต้องหลังขั้นนี้)
5. แท็บ **สี / ROI**:
   - ติ๊ก **หยุดภาพ (freeze)** → เลือกสี → โหมด **ลากเรียนสีป้าย** → ลากกรอบเล็กๆ *ในเนื้อสี* ของป้ายสีนั้น
     (ทำครบทุกสี ถ้าแสงต่างกันหลายจุด ติ๊ก "เรียนเพิ่ม" แล้วลากป้ายเดิมตอนอยู่อีกมุมได้)
   - ถ้ากำแพง/พื้นโดนจับเป็นป้าย → โหมด **ลากเรียนสีพื้นหลัง** → ลากบนกำแพงตรงนั้น
     (ระบบจะรับเฉพาะพิกเซลที่ "เหมือนป้ายมากกว่าเหมือนกำแพง")
   - ติ๊ก **ดู mask ของสีนี้** เพื่อดูผล ปรับแถบ H/S/V ละเอียดได้
   - โหมด **ลาก ROI** = กำหนดพื้นที่ตรวจจับ, โหมด **ลากโซนตัดทิ้ง** = ปิดจุดที่ไม่ต้องการ (คลิกขวาเพื่อลบโซน)
6. แท็บ **Calibrate → 2) จุดกระทบ** แก้ปัญหา "เล็งตรงแต่ยิงไม่โดน" **ทำอัตโนมัติทั้งหมด ไม่ต้องกดให้ทันแสง**
   - ตั้งกระดานขาวด้าน (กระดาษ A3/ฟิวเจอร์บอร์ด) ให้ตั้งฉากกับหุ่น แล้ววัดระยะจาก **กล้อง** ถึงกระดาน = Z
     หรือแปะป้าย 1 ใบบนกระดานแล้วติ๊ก "วัด Z จากป้าย" (ต้อง calibrate HFOV แล้ว)
   - หันกล้องให้กระดานอยู่กลางภาพ → ใส่ Z → **▶ Auto** (ค่าเริ่มต้น 5 นัด)
     โปรแกรมเก็บภาพก่อนยิง → ยิงเอง → **บันทึกทุกเฟรม 1.5 วิ** → หาเฟรมที่มีแสงแฟลช → หาจุดศูนย์กลาง
     → ตัดนัดที่หลุดกลุ่ม → เซฟรูปที่มาร์กจุดไว้ใน `logs/calib/`
   - ย้ายหุ่นไปอีก 2 ระยะ (เช่น 60 / 90 / 120 ซม.) ทำซ้ำ → **📊 สรุปผล**
     จะได้ `calib_report_ir.txt` + `calib_plot_ir.png` บอกว่าถ้าเล็ง crosshair จะคลาดกี่ ซม. และหลัง calibrate เหลือกี่ ซม.
   - **🎯 ทดสอบความแม่น ก่อน/หลัง**: แปะป้าย 1 ใบบนกระดาน → โปรแกรมยิงสลับ "เล็งแบบเดิม (crosshair)" กับ "เล็งด้วยโมเดล"
     แล้ววัดจากภาพว่าแต่ละนัดคลาดกี่ ซม. และโดนป้ายไหม → `accuracy_test.txt/csv` ใส่รายงานได้เลย
   - ถ้าหาแสงไม่เจอ: ลดแสงห้อง, ใช้กระดานขาวด้าน (ไม่เงา), เข้าใกล้ขึ้น
     หรือใช้ปุ่มสำรอง "ยิงแล้วคลิกเอง" ซึ่งภาพจะหยุดที่ **เฟรมที่แฟลชเด่นสุด** ให้คลิก (ไม่ต้องกดทัน)
   - กระสุนเจล: เลือก "กระสุนเจล" แล้วทำชุดแยก ใช้ปุ่มสำรองคลิกรอยกระสุนบนกระดาษ (เจลไม่มีแสง)
   - ถ้ายิงจริงแล้วยังคลาดทางเดียวกันทุกนัด ใช้ปุ่มปรับละเอียด ◀ ▶ ▲ ▼
7. **บันทึกค่าทั้งหมด** (ไฟล์ settings.json) ครั้งหน้าเปิดมาจะโหลดค่าเดิมให้เลย

## ข้อมูลจากสนามจริง (29 ก.ย.) และสิ่งที่ปรับตาม
- **ระยะจากขนาดป้ายถูกต้อง**: ป้ายแดง 6×9 ที่วางห่าง 60 ซม. โปรแกรมคำนวณได้ 63–65 ซม. (วัดจากตัวกล้อง) แปลว่า HFOV 96° ใช้ได้
- **ป้ายที่ล้มแล้วไม่ถูกตรวจจับซ้ำ** ใช้เป็นการยืนยันว่ายิงโดนได้
- **กำแพงสนามสีเหลือง** (H≈25, S≈115–135): ปรับค่าเริ่มต้นของ YELLOW เป็น S≥165 จนกำแพงหลุดจาก mask หมด
  ทดสอบกับรูปจากสนามจริงแล้ว (ยังควรเรียนสีป้ายเหลืองจริงอีกครั้ง)
- **พื้นมันสะท้อนเงาป้าย**: ถ้าเจอป้ายสีเดียวกันอยู่ใต้กันในแนวเดียวกัน จะตัดอันล่างทิ้ง
- **กระสุนเจลเล็งด้วย crosshair กลางป้ายที่ ~60 ซม. วัดรอยน้ำมันได้ ซ้าย 1.0 ซม. และต่ำ 2.6–2.9 ซม.** (1 นัด)
  ใส่เป็นค่าเริ่มต้นของโมเดลเจลไว้แล้ว (ซ้าย 1.0 / ต่ำ 2.75 ซม.) เก็บเพิ่มได้ในแท็บ Calibrate → 2b
- **ป้อนกระสุนไม่สม่ำเสมอ (สั่ง 3 ครั้งออก 1 นัด)**: โหมดเจลจะยิงซ้ำจนกว่าภาพยืนยันว่าป้ายล้ม
  สูงสุด 8 ครั้ง ปรับได้ในแท็บยิง ก่อนยิงซ้ำทุกครั้งจะเล็งใหม่ให้ก่อน
  ถ้าป้ายหายไปจากภาพ **ติดกัน 3 ภาพ** (`confirm_knock_frames`) จะถือว่าล้ม ถ้าแค่เล็งไม่เข้าแต่ยังเห็นป้าย ไม่นับว่าล้ม
  ส่วน `logs/shots.csv` บันทึกว่าสั่งยิงกี่ครั้ง (`triggers`) และป้ายล้มหรือไม่ (`knocked`)
  (ไฟล์ shots.csv รูปแบบเก่าจะถูกเปลี่ยนชื่อเป็น `shots_old_<เวลา>.csv` อัตโนมัติ)
- **ป้ายหันเฉียง**: ความกว้างคิดจาก พื้นที่ ÷ ความสูง แทนกรอบ bbox (ป้ายเฉียงเป็นสี่เหลี่ยมด้านขนาน bbox จะกว้างเกิน
  ทำให้ป้ายตั้งกลายเป็นจัตุรัส)
- **เงาบนพื้น** ตัดเฉพาะก้อนที่กว้างเท่าป้ายด้านบน (ป้ายจริงอีกใบที่อยู่คนละระยะจะไม่โดนตัด)
- **วงกลม vs จัตุรัส** ใช้ "พื้นที่ ÷ วงกลมล้อมรอบ" (วงกลม ≈0.9, จัตุรัส ≈0.64) แทน circularity
  (วงกลมเล็กในภาพขอบเป็นขั้นบันได circularity เหลือ ~0.75 เลยเคยถูกจับเป็นจัตุรัส) เกณฑ์ `circle_min_fill` = 0.74
- **ป้ายที่ถูก ROI/โซนตัดทิ้งตัด** จะไม่ถูกนับ (ขนาดผิด -> ระยะผิด -> จุดกระทบผิด)
- **หาแสง IR ตอน calibrate ใช้ ROI ด้วย** (29 ก.ย. รอบแรกไปจับคนที่เดินอยู่เหนือกำแพงโฟมแทนจุด IR ทั้ง 3 นัด)

## ตอนยิง
- แท็บ **ยิง**: ติ๊กสีและรูปทรงที่อนุญาต หรือใส่ "คู่เฉพาะ" เช่น `RED:HORIZONTAL, BLUE:CIRCLE`
  (กันยิงผิดเป้าที่โดนหัก −1 คะแนน)
- **🎯 ยิงทุกเป้าที่ตรงสเปคในภาพ** → ระบบจำตำแหน่งเป้าทั้งหมดเป็นมุม gimbal แล้วเล็งยิงทีละใบ (ซ้าย→ขวา หรือใกล้สุดก่อน)
- โหมดเมาส์ **คลิกยิงป้ายนี้** → คลิกป้ายในภาพเพื่อยิงเฉพาะใบนั้น
- **มุมล็อค** (แท็บ Gimbal) = มุมเริ่มต้นตอนค้นหา และ **ขอบเขต yaw/pitch** กัน gimbal หมุนไปยิงนอกสนาม
- W A S D หมุน gimbal ด้วยมือ, **Space = STOP**
- ทุกนัดบันทึกลง `logs/shots.csv` (สี, รูปทรง, ระยะ, error ตอนยิง, มุม gimbal สัมบูรณ์ ใช้วาดตำแหน่งเป้าบนแผนที่ได้)

## หลักการ (ใช้ในรายงาน/นำเสนอ)
**ตรวจจับ**
1. CLAHE บนช่อง L ของ Lab ลดผลแสงไม่สม่ำเสมอ
2. mask สีด้วยช่วง HSV ที่เรียนจากภาพป้ายจริง ใช้ percentile 2–98 ของ hue แบบวงกลม (รองรับสีแดงที่อยู่ทั้งสองฝั่ง 0/180)
3. **Back-projection**: histogram H-S ของป้าย เทียบกับ histogram ของพื้นหลัง รับเฉพาะพิกเซลที่ P(ป้าย) > P(พื้นหลัง)
   ทำให้แยกป้ายออกจากกำแพงสีคล้ายกันได้
4. **แสงสะท้อนบนอะคริลิก**: พิกเซลที่ V สูงและ S ต่ำ ที่อยู่ภายใน convex hull ของก้อนสี จะถูกเติมกลับเป็นส่วนของป้าย
   (ไม่เติมถ้าอยู่นอก hull เพื่อไม่ให้ไปรวมกับเสาสีขาว)
5. แยกรูปทรงจาก circularity, rectangularity (minAreaRect) และ aspect ratio
   โดยแก้ความยืดของเลนส์มุมกว้างที่ขอบภาพก่อน (ยืด 1/cos²θ ตามแนวรัศมี)
6. **ระยะ** Z = f × ขนาดจริง ÷ ขนาดในภาพ คิดจากทั้งความกว้างและความสูง
   ถ้าสองค่าไม่สอดคล้องกันแสดงว่าเป็นของปลอม ตัดทิ้ง

**เล็ง/ยิง**
- จุดกระทบในภาพ: `u = cx + A + B/Z`, `v = cy + A + B/Z (+C·Z สำหรับเจล)`
  B/Z มาจาก parallax (กล้องกับลำกล้องอยู่คนละตำแหน่ง) A มาจากแกนที่เอียงต่างกัน และ C·Z มาจากกระสุนตก
  → offset ขึ้นกับ **ระยะ** ไม่ใช่ลำดับป้าย จึงไม่ต้องไล่ปรับทีละป้าย
- **Look-then-move**: แปลง error พิกเซลเป็นมุม (atan(e/f)) แล้วสั่ง `gimbal.move` ด้วยมุมนั้นตรงๆ
  รอ gimbal นิ่งและภาพตามทัน แล้ววัดใหม่ ทำซ้ำจนคลาดไม่เกิน tolerance ติดกัน 2 ครั้งจึงยิง
  ไม่แกว่งเหมือน PID ความเร็วที่เจอปัญหา delay ของภาพ
- ตรวจทิศการหมุนด้วย phase correlation (หมุน 4° แล้วดูว่าภาพเลื่อนไปทางไหน) และจำกัดมุมตามขอบเขตที่ตั้งไว้

## ผลทดสอบในฉากจำลอง (`--selftest`)
ฉากมีป้าย 5 ใบที่ระยะ 100–150 ซม. บนกำแพงสีส้มอ่อน มีแสงสะท้อนบนป้าย
ลำกล้องเยื้องกล้อง 1.5 ซม. / 5.5 ซม. และแกนเอียง 0.7° / 0.5°
- ก่อน calibrate จุดกระทบ: ยิงไม่โดนเลย (เหมือนอาการของหุ่นจริง)
- หลัง calibrate 4 ระยะ: IR โดน 5/5 และเจลโดน 5/5 (RMS ของโมเดล 0.2 px)
- calibrate อัตโนมัติ (แสงติด 0.25 วิ ภาพช้า 0.3 วิ): จับแสงได้ทุกนัด ทดสอบก่อน/หลังที่ 1 ม. คลาดจาก 6.8 เหลือ 0.4 ซม.
- กำแพงสีแดงใกล้เคียงป้ายแดง: ก่อนเรียนสีตรวจไม่เจอป้ายแดง หลังเรียนสีป้าย+พื้นหลังเจอครบ

## ข้อควรรู้
- โซนตัดทิ้งเป็นพิกัด **บนภาพ** เหมาะกับการตัดส่วนที่ติดกับกล้อง เช่น ลำกล้อง ไฟ หรือขอบภาพ
  (เมื่อ gimbal หมุน โซนจะไม่ตามวัตถุในโลก)
- โหมดไฟล์ภาพ/วิดีโอใช้ทดสอบการตรวจจับและเรียนสีจากภาพที่แคปไว้ได้ (ไม่มี gimbal)
- ใช้ IR ทดสอบก่อนเสมอ ส่วนเจลต้องติ๊กยืนยันก่อนยิง
